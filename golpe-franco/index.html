04 / INFORMACIÓN

UNA WEB, TODAS LAS VERSIONES

¿CAMBIA LA DIRECCIÓN?

El objetivo es mantener esta misma dirección para las próximas entregas. Solo se actualizan el historial y los enlaces.

¿POR QUÉ NO DESCARGA AHORA?

El ZIP grande necesita alojamiento compatible; el repositorio de esta web no es un depósito para juegos de más de 1 GB.

¿PUEDO DESCARGAR UN ARCHIVO ÚNICO?

Sí, cuando el paquete esté alojado. La ficha está diseñada para ofrecer un único enlace al archivo final.

¿QUÉ CAMBIARÁ EN EL FUTURO?

Cada versión podrá incluir notas nuevas y un enlace comprobado, manteniendo el diseño y la dirección.
